# Project Vehicles Dashboard

This project is a web application developed with Streamlit to explore a dataset of used vehicle advertisements.

The application allows users to interactively visualize vehicle data through:

- A histogram showing the distribution of vehicle mileage.
- A scatter plot showing the relationship between vehicle mileage and price.

## Technologies used

- Python
- Pandas
- Plotly
- Streamlit

## Dataset

The project uses the `vehicles_us.csv` dataset, which contains information about used vehicle advertisements, including price, model year, mileage, condition, transmission type, and other vehicle characteristics.

## Web application

The application is deployed on Render.

Application link: https://project-vehicles-dashboard-assq.onrender.com
